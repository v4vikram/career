## Kaise use karna hai

Jis track pe kaam karna hai, uska ROADMAP kholo. Wo bata dega aaj kya karna hai —
decide karne mein time waste nahi.

Dono ek saath chalane ho to: **DSA subah, System Design shaam.** Ya alternate din.
Dono roadmap alag-alag chalte hain — ek track chhod dene se dusra kabhi break nahi hota.
Dono mein asli cheez **Day number** hai, date nahi. Miss ho jaye to wahin se uthao.

Commit karna:
```bash
git add . && git commit -m "day N: <topic>" && git push
```

> **Ek hi rule:** notes usi numbered file mein jaate hain jahan wo belong karte hain.
> Naya folder nahi. Reorganise nahi. Kahin fit na ho to us track ke qa-bank ke
> bottom mein daal do aur aage badho.
