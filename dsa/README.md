# DSA — 6 LPA Track

Coding round clear karne ke liye. Pattern-based approach — 300 random problems
nahi, wo 10 patterns jo screening aur first round mein baar-baar aate hain.

**Target:** 6 LPA backend / fullstack role
**Language:** JavaScript (jo bhi interview mein likhoge)
**Level:** Easy + Easy-Medium. Is band pe hard problems nahi aate.

## Kaise use karna hai

1. **[ROADMAP.md](ROADMAP.md)** kholo — wo batayega aaj kya karna hai. Khud decide mat karo.
2. Pattern file padho. Har file mein **template code** hai jo yaad karna hai.
3. Us pattern ki problems solve karo — **pehle khud, phir solution dekho.**
4. Table mein tick karo jab pattern ko **bina dekhe** likh pao.

> **Rule:** har problem ka solution usi pattern file ke bottom mein likho.
> Naya folder nahi banana.

## Rules jo bachate hain

- **Brute force pehle bolo, phir optimize karo.** Interviewer yahi dekhta hai.
- **Har solution ke baad time + space complexity bolo** — bina poore.
- **Edge cases:** empty array, single element, saare same, negative numbers.
- Atak jao to **chup mat raho** — jo soch rahe ho wo bolte raho.
